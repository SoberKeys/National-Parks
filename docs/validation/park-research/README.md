# PARK RESEARCH

One file per validation park. **Nothing in these files may be published to a participant until it is
field-verified.** See the source-tier system below.

## Source tiers

| Tier | Meaning | May be published? |
|---|---|---|
| **T1 — NPS official** | nps.gov, the NPS Data API, a park InfoGuide PDF, a ranger | **Yes**, with source URL and date |
| **T2 — Reputable secondary** | AllTrails, established guidebooks, local running clubs, regional press | **No** — use as a lead, then confirm at T1 or T3 |
| **T3 — Field-verified** | We or a trusted local ran it and recorded a GPX, on a stated date | **Yes**, with the date |
| **T0 — Unverified** | Anything else, including recall | **Never** |

**Publication rule: a route may be published only when its distance, surface, access and legal status
are each at T1 or T3.** A T2 distance may be shown as "approximately", clearly labelled, only if the
route itself is T1/T3 confirmed.

## ⚠️ Open design decision — surfaced Day 1, needs a founder call

Real trail geography does not produce clean 5K and 10K distances:

| Park | Candidate route | Actual distance (T2) |
|---|---|---|
| Acadia | Eagle Lake Carriage Road Loop | 5.9–6.0 mi ≈ **9.7 km** |
| Acadia | Ocean Path out-and-back | 4.4 mi ≈ **7.1 km** |
| Shenandoah | Lewis Spring Falls Loop | 3.3 mi ≈ **5.3 km** |
| Shenandoah | Milam Gap + Lewis Falls Loop | 6.2 mi ≈ **10.0 km** |
| Zion | Pa'rus Trail out-and-back | 3.5 mi ≈ **5.6 km** |

Labelling these "5K" and "10K" would force artificial turnaround points that do not match trailheads,
junctions, or anything a runner can see on the ground — and an invented turnaround is exactly the kind
of instruction that puts someone in the wrong place.

**`RECOMMENDATION` — name challenges by the route and state the real distance**, using tier names
(**EXPLORER** / **ADVENTURE**) rather than exact race distances:

- `ACADIA · EXPLORER — Ocean Path Out-and-Back · 4.4 mi (7.1 km)`
- `ACADIA · ADVENTURE — Eagle Lake Carriage Road Loop · 5.9 mi (9.5 km)`

This is more honest, matches how these places actually work, and removes a whole class of navigation
risk. The cost is losing the instant legibility of "10K". **Founder decision required — flagged at
Gate 1, not blocking before then.**
